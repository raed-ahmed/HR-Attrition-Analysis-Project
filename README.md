# 📊 HR Attrition Analysis Project

## 📌 Overview

The **HR Attrition Analysis Dashboard** provides a comprehensive view of employee turnover, helping to identify key factors affecting attrition and workforce stability. It enables HR teams to analyze patterns, detect high-risk areas, and support data-driven decision making.

## 🚀 Features

* 👥 **Employee Overview**

  * Total Employees: **2,925**
  * Attrition Count: **492**
  * Attrition Rate: **16.8%**

* 💰 **Salary Insights**

  * Average Salary: **6.5K**
  * Average Salary Raise: **15.22%**

* 😊 **Employee Metrics**

  * Average Job Satisfaction: **2.7**
  * Average Age: **37**

* 🏢 **Department Analysis**

  * Highest Attrition: **R&D Department (57.3%)**
  * Followed by: **Sales (37.8%)**

* 👤 **Demographic Insights**

  * Highest Attrition Age Group: **25–34 (47.4%)**
  * Gender Distribution:

    * Male: **63.4%**
    * Female: **36.6%**

* 💼 **Job Role Analysis**

  * Top Roles with Attrition:

    * Laboratory Technician (**26.4%**)
    * Sales Executive (**23.0%**)
    * Research Scientist (**20.1%**)

* 🎓 **Education Field**

  * Highest Attrition: **Life Sciences (38.6%)**

* ✈️ **Business Travel**

  * Frequent Travelers: **66.1% attrition impact**

* 💍 **Marital Status**

  * Highest Attrition: **Single (49.4%)**

## 🎛️ Dashboard Controls

* 🧭 **Filter by Department**: HR, R&D, Sales
* 👥 **Filter by Gender**: Male, Female
* 🔄 **Clear Filters**: Reset all filters
* 🏠 **Back to Home**: Navigate to main page
